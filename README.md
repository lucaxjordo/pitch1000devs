# Projeto de Apresentação de Pitch - 1000devs

Este projeto foi desenvolvido como uma alternativa criativa ao uso de ferramentas tradicionais como PowerPoint para apresentações. O site foi criado para servir como suporte visual durante um pitch no programa 1000devs, destacando minha jornada e habilidades em desenvolvimento de sistemas.

## Visão Geral

O site é composto por duas páginas principais:

1. **Página Inicial (`index.html`)**: Apresenta uma breve introdução sobre mim, Lucas Vinicius de Oliveira, incluindo minha formação, experiências e objetivos profissionais. A página é estilizada com um design limpo e moderno, utilizando uma paleta de cores suaves e fontes legíveis.

2. **Página de Cards (`card_slider.html`)**: Contém um slider interativo que exibe uma série de cards. Cada card apresenta uma mensagem motivacional ou um aspecto da minha jornada, acompanhado de uma imagem ilustrativa. O slider permite a navegação entre os cards de forma fluida e responsiva.

## Funcionalidades

### Slider de Cards

- **Navegação Interativa**: Os cards podem ser navegados utilizando os botões ">" (próximo) e "<" (anterior).
- **Efeitos Visuais**: Cada card é animado com transformações CSS, incluindo translação, escala, rotação e desfoque, criando uma experiência visual dinâmica.
- **Responsividade**: O slider é responsivo, adaptando-se a diferentes tamanhos de tela.

### Design e Estilo

- **Gradiente Dinâmico**: O fundo da página de cards utiliza um gradiente linear que muda suavemente de cor, adicionando um toque moderno e atraente.
- **Tipografia**: As fontes utilizadas são `DM Sans` para textos comuns e `monospace` para elementos específicos, garantindo legibilidade e consistência visual.
- **Ícones e Imagens**: Ícones e imagens são utilizados para complementar o conteúdo textual, tornando a experiência mais visual e engajante.

## Estrutura do Projeto

- **HTML**: Estruturação do conteúdo das páginas.
- **CSS**: Estilização e animações, incluindo responsividade.
- **JavaScript**: Lógica para o funcionamento do slider de cards.

## Como Utilizar

1. Clone o repositório para sua máquina local.
2. Abra o arquivo `index.html` no seu navegador para visualizar a página inicial.
3. Navegue até a página de cards clicando no link "Vamos para antes do início!" no rodapé.
4. Utilize os botões ">" e "<" para navegar entre os cards.
